# N4 Express: course content

Static lesson site for **N4 Express**, a bilingual (English + 繁體中文) Japanese course from zero to JLPT N4.
It is shown inside the N4 Express app (Base44 web app and Android app), which handles accounts, saved progress and subscriptions.

- `index.html`: Week 1 (hiragana, grammar, words, role-play, drills, gate test)
- `audio/`: audio clips for every kana, word and dialogue line
- `worksheets/`: printable handwriting workbook

Credits: stroke data from KanjiVG (CC BY-SA 3.0); kana font Klee One (SIL OFL).
Audio in this beta is generated with neural text-to-speech voices and will be replaced with commercially licensed recordings before paid launch.
